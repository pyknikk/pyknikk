## Featured project

### [FretLab](https://github.com/pyknikk/FretLab) · [Live demo](https://pyknikk.github.io/FretLab/)
A guitar and music theory studio that runs in the browser. It has ten tools: fretboard and ear training, chord progression and solo analysis, a CAGED/triads visualizer, a riff generator with tab export, and a rhythm trainer.
Built in plain JavaScript (ES modules) with the Web Audio API. No framework and no build step.
